# NLP-Based-Sentiment-Analysis- 
Developed a sentiment analysis system for 1,440 e-commerce customer reviews, classifying them as Positive, Negative, or 
Neutral.
•
Implemented text preprocessing and TF-IDF feature engineering, handled Hindi text, emojis, and sentiment-sensitive words, 
and tuned Linear SVM using GridSearchCV, achieving 80.21% test accuracy.
•
Deployed the trained model using Streamlit and Joblib for real-time sentiment prediction.
